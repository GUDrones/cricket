| Prefix    | Meaning                                          |
| --------- | ------------------------------------------------ |
| feat:     | Feature – Adding a new feature                   |
| fix:      | Fix – Bug fix                                    |
| docs:     | Documentation – Changes to documentation         |
| style:    | Style – Code style changes (formatting, etc.)    |
| refactor: | Refactor – Code refactoring (no feature/bug fix) |
| perf:     | Performance – Performance improvement            |
| test:     | Test – Adding/modifying tests                    |
| build:    | Build – Build system changes (npm, make, etc.)   |
| ci:       | CI – Continuous Integration changes              |
| chore:    | Chore – Minor tasks (e.g., package updates)      |
| revert:   | Revert – Reverts a previous commit               |
